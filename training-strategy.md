# Training Strategy — GZCLP (Blacknoir)

Originally written as a June 2026 handoff doc to set up a returning-from-layoff
GZCLP run; that one-time setup (fixing inflated starting 1RMs via the Liftosaur
MCP) is long done. What's left here is what's still true: the program decision
and the guiding principle behind it. For anything about current training state
(what's next, current weights, T3 exercise selection) — trust `fitness.db` and
the Liftosaur MCP, not this doc; that stuff has moved on since June and this
file won't track it.

## Program (settled, don't re-litigate)

- Running **GZCLP: Blacknoir version** — Liftosaur program id **`viohtrec`**.
- Using the **modified** exercise templates (`t1_modified` / `t2_modified` /
  `t3_modified`), not advanced — intentional, keep it boring.
- Blacknoir was chosen specifically because it drops the disliked 10x1 T1 stage.
  The no-10x1 cascade (2x5 → 3x3 → 4x2 → 5RM retest → reset to 85%) is wired in
  correctly. Leave it.
- Increments: squat/deadlift +10 lb/session, bench/OHP +5 lb/session. Leave them.
- T3 accessory slots rotate based on available equipment and haven't been fixed
  to one pair since setup — check `fitness.db` for what's actually in rotation
  rather than assuming a specific exercise list here.

## Guiding principle (durable — applies beyond the original comeback)

Let the linear progression do the work; don't manually jump weights. Muscles
rebound fast after time off, but tendons/connective tissue readapt slower, and
that lag is where injuries happen — undershooting costs a few boring sessions,
overshooting costs a stall, a reset, or worse. This held for the original
comeback and still holds for any future weight/program adjustment: bias toward
conservative, let the app's LP self-correct rather than intervening by hand.
